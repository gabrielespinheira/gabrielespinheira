# Gabriel Espinheira

Senior full-stack engineer, design-minded, based in Lisbon. I build web products end to end, from the data model to the interface people touch, including the AI features inside them.

I've been building for the web since 2014, across payments, investment, healthcare SaaS, Web3 and property management. Today I work in TypeScript on Next.js, Convex, Expo and Electron, and I write the tests first so coding agents have a spec to work from.

At a European payments company I led engineering on the website revamp, working with marketing, design and business to build and launch it. Then I moved to Support and built AI into its chat, email and voice channels.

## Work

- **[SharpOS](https://www.gabs.app/work/sharpos)**: the platform my web studio runs on. A workspace per client for pages, boards, forms and support, on web, desktop and mobile, where my team and AI agents share one API.
- **[Relay](https://www.gabs.app/work/relay)**: my Mac app for AI work, where agents write, draw, speak and render films in one project.
- **[Fabricator UI](https://www.gabs.app/work/fabricator-ui)**: over 60 accessible React components you install as source code, compatible with shadcn/ui. [Source](https://github.com/gabrielespinheira/fabricator-ui).
- **[Taste Vault](https://www.gabs.app/work/taste-vault)**: websites I study, each rebuilt by a coding agent from a prompt another agent wrote, shown beside the original.
- **[SnapForge](https://www.gabs.app/work/snapforge)**: a free browser editor that puts a screenshot or screen recording in a 3D device frame and exports a 4K image or a short video.

Most of these live in private repos. Each write-up on [gabs.app/work](https://www.gabs.app/work) shows how I built it.
